Emotion Sense Text Analyzer in Marathi using NLP



A Natural Language Processing (NLP) project that analyzes Marathi text and classifies it into predefined emotion categories using text preprocessing and machine learning techniques.



Emotions

\- आनंदी (Happy)

\- दुःखी (Sad)

\- राग (Angry)

\- भीती (Fear)

\- आश्चर्य (Surprise)

\- तटस्थ (Neutral)



Tech Stack

Python • Pandas • NLTK • Scikit-learn



Workflow

Dataset → Preprocessing → Feature Extraction → Model Training → Emotion Prediction
